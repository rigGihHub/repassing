# Repassing v0.1 — Foundation

**Play more. Waste less.**

First technical foundation for Repassing: a mobile-first sports reuse marketplace.

## Included
- Next.js + React + TypeScript
- Responsive mobile-first landing/marketplace shell
- Repassing work logo
- Swedish `/sv` and English `/en`
- PostgreSQL + Prisma starter model
- Health endpoint `/api/health`
- GitHub Actions CI
- Architecture/decision docs

## Run locally
1. Install Node.js LTS.
2. Open this repository folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

The visual shell works without a database. Database setup comes in the next vertical release.
