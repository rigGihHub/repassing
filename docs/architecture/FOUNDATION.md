# Repassing v0.1 Foundation

## Product
Repassing is a mobile-first marketplace for reuse of sports clothing and equipment, initially centered on sports clubs.

## Principles
- Think big. Architect correctly. Launch small.
- Mobile first.
- Organization-aware, never organization-hardcoded.
- Server-side authorization for protected actions.
- Money stored as integer minor units + ISO currency.
- Swedish first, international-ready.
- Payment provider must be abstracted before real marketplace payments are added.

## v0.1 scope
This release proves the visual and technical foundation only:
- Responsive public shell
- Swedish and English entry points
- Repassing work logo
- Design tokens
- PostgreSQL/Prisma starter schema
- Health endpoint
- CI build/typecheck
- Foundation ADR

No authentication, live listings, payments or production marketplace behavior is included yet.
